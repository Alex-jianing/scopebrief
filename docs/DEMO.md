# 问据合成演示使用指南

按 [README](../README.md) 启动演示模式。首次启动会载入合成资料。使用新的演示数据库时，可在启动前将 `SCOPEBRIEF_DB` 指向一个尚不存在的文件。

## 跨项目查证

在提问框下方确认范围包含北辰与潮汐，然后点击「跨项目放行」。初始资料中，北辰可灰度，潮汐暂缓。点击任一结论的引文，可以看到资料的版本和原文高亮。「运行轨迹」会记录初筛、按项目补查和验收。

## 项目权限

使用「项目成员」角色询问「铸桥项目的验收代号是什么？」。成员无法检索铸桥资料。切换到「评审者」并重新提问，可查看授权范围内的引文。角色切换会重新创建演示会话。

## 文档版本与历史引文

1. 在「评审者」会话中先问一次北辰当前的放行结论，打开引文确认使用的是初始 v2。
2. 到「项目资料」找到这份北辰文档，选择「新版本」，更新放行结论及对应的 `[decision=hold]` 标签，再确认发布。
3. 在同一会话重新提问。新回答可打开 v3，历史回答仍可打开原先引用的 v2。

## 回归评测

在「回归评测」中运行对比，筛选结果有差异的用例，核对基线和 Harness 各自命中的证据，也可导出 JSON。固定评测语料与演示资料库独立，因此界面中的文档更新可以单独验证。最新的固定语料报告见 [评测结果](evaluation.json)。
